# Immersive columns and migration review

Postimplementation source/mounted review for pre.1. Stock Kit controls, colors and typography remain. No Button/Input/Checkbox variants were changed; the requested ghost collapse button conflicts with the permanent stock-control policy. Its wrapper moves 4px left beside the status count instead.

The full-width empty header is removed. macOS caption reserve occupies the sidebar rail; the command/search/table column begins at the top, and collapsed macOS rail reserves 80px for native traffic lights. Windows native TitleBar tabs stay within the right column. Layout helpers remain geometry-only. Sidebar blur remains unverified/deferred.

Found and fixed a concrete layout defect: a sidebar width was accidentally applied to the entire content row, clipping right-column controls. Restored real mouse checkbox/link tests now pass. Expanded/collapsed light/dark geometry additionally asserts a minimum 600px right command column at 880px window width, preventing that clipping regression.

Ubuntu-sensitive removal tests no longer assume which popup item pointer hover or arrow counts select. The test captures the exact production Remove menu item callback before sorting, then activates that deferred, stable-ID callback and clicks real Cancel/Remove records only dialog controls. Other tests retain real keyboard Details, Escape, filtering and blank-space paths. No tests are ignored or removed. This is callback/adapter evidence, not certification of native menu accessibility.

Migration review uses Kit alerts and native file/folder pickers. Bounded UTF-8 HTTP-only EF2/text parsing discards recognized headers and rejects credentials/cookies/authorization/POST/unknown fields. Import requires destination review and stopped/idle unscheduled queues, no automatic dispatch. Export warns about private signed URLs and uses no-clobber staging. Core tests cover malformed/oversized input, symlinks, existing-output preservation and simultaneous-export races. Native wizard/accessibility/focus/contrast and cross-app IDM acceptance remain separate unverified checks.

No global screenshots, user's downloads, public swarms, real power providers or OS security changes were used. See docs/STATUS.md for checks and release status.
