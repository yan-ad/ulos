# Table-aligned commands and Windows Setup

Postimplementation source/mounted review, following the user's requested review timing. This does not certify native Windows rendering, accessibility or installer wizard behavior.

## Direction

Use the existing stock Kit theme and controls. ENERGY 1 / RHYTHM 1 / MOTION 1: no decorative assets, custom caption buttons or new animation. A Kit ToolbarGroup names the six related download actions; controls enter through content so Kit does not silently resize/restyle Buttons. The toolbar/search row occupies the DataTable column and follows the sidebar's real expanded/collapsed geometry. The stock sidebar icon Button moves beside the bottom download count, outside the toolbar; it is not shrunk in violation of permanent control policy. Remove the selection-toolbar Details action; row menus/links/keyboard retain per-download Details. Options/theme sit before search, with Scheduler retained.

Windows alternate-tab actions are stock icon Buttons with names/tooltips rather than wide text Buttons, so they fit in the 625px table column at 880px minimum window width. macOS keeps native traffic lights in a separate Kit titlebar above the independent toolbar. No controls are painted manually.

## Behavior and layout evidence

- Mounted light/dark expanded/collapsed tests check the sidebar toggle beside the count, outside the toolbar; table-column left alignment; removed Details; command/search non-overlap; stock Button geometry.
- Windows command-tab harness reserves the expanded 255px sidebar and checks all controls/search at minimum window width. Search value persists between tabs.
- The real localhost verified-range pause/resume fixture now resumes through a toolbar click. Queue slot, next queued item, resumed If-Range requests and final bytes are still asserted.
- Existing row-menu, file-policy, cancellation, consent and scheduler tests remain enabled.
- Setup is a real compiled Inno installer, not a ZIP renamed EXE. Stock wizard pages show the MIT license and complete supplied third-party notices. Installed notices remain readable offline. Installer is per-user with lowest privileges; no auto-launch, forced app close, association takeover or download/history purge.

## Outstanding review gates

1. **HIGH: native Windows visual/keyboard/accessibility evidence incomplete.** Adapter geometry on macOS does not establish Windows DPI, first paint, screen-reader operation, roving focus, high contrast or caption behavior. Native review remains required before claiming the GUI complete.
2. **HIGH: sidebar blur deferred.** GPUI exposes window backdrop requests but no success/capability signal in the reviewed public API. The current stock sidebar and root are opaque, with no verified high-contrast/reduced-transparency fallback. Structure is ready for independent material treatment, but no fake or unsupported blur is claimed.
3. **HIGH: installer runtime/wizard review required.** CI compiles both architecture branches using the real compiler, and real binary Setup artifacts are built after Windows checks; compilation does not prove standard-user install/upgrade/uninstall, notice-page usability, worker load, SmartScreen or ARM64 runtime. No OS security changes are used to bypass signing warnings.
